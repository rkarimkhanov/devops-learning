I've been working in Linux system administration for a few years. Most of the automation I did was reactive — something breaks, you write a script to fix it or prevent it from happening again. This repo is me being more intentional about it: cleaner structure, proper practices, and actually documenting what I build.

Moving into DevOps is a natural next step. The mindset is the same — automate what's manual, handle failures properly, don't leave things to chance.
